Pay for every AI answer only once.

Your app's tests call OpenAI or Claude, so every test run costs money, takes ages, and gets a slightly different answer. Promptape records the real answers the first time, then plays them back: free, instant, and the same every time.

The first time, each call really goes to the AI company. Promptape passes the answer back to your test and keeps a copy on tape. Example: 40 calls to Claude Opus 5.5, each sending about 900 words and getting about 220 back (1,200 and 300 tokens), at list price. Your numbers depend on your app.

Set up in about a minute

No code changes. The official SDKs, and frameworks built on them like LangChain and the Vercel AI SDK, read their address from an environment variable.

1

Start Promptape

It runs on your computer and saves recordings in a tapes folder.

$ promptape
  ◉ promptape v0.1.1  mode=auto

  listening  http://127.0.0.1:4000
  tapes      tapes
Leave this window open. Promptape prints a line for every call it records or replays.
2

Point your app at it

In a second terminal, where you run your tests. Your real key still works and is only used while recording.

export OPENAI_BASE_URL=http://127.0.0.1:4000/v1
export ANTHROPIC_BASE_URL=http://127.0.0.1:4000
$env:OPENAI_BASE_URL = "http://127.0.0.1:4000/v1"
$env:ANTHROPIC_BASE_URL = "http://127.0.0.1:4000"
3

Run your tests twice

Use your usual test command. The first run records, every run after that is free. Then ask Promptape what you saved.

$ pytest              # or npm test, go test…
$ pytest              # same command, now from tape
$ promptape report    # what a live run would cost
In the Promptape window, the first run shows RECORD lines with what each call cost, and every run after shows REPLAY lines with what each one saved.

Small tool, careful details

Your keys stay secret

Promptape never writes API keys to disk, so the tapes are safe to commit to git.

Streaming just works

Answers that arrive word by word are recorded and replayed exactly the same way.

Any language

Python, TypeScript, Go, Java: if it can talk to the API, it can talk to Promptape.

Errors are kept too

A real "bad request" is saved so you can test how your app handles it. Rate limits never are.

A receipt every time

It tells you what each call cost, and what each replay saved you.

Tiny and dependency-free

One program, written in Go, nothing else to install. Also ships as a Docker image.

A tape is just a file

One readable file per question, saved next to your tests. Change a prompt, and the pull request shows exactly how the AI's answer changed.

// tapes/anthropic/claude-opus-5-5-252590dd6997.json
// (shortened example: real tapes also keep headers and streamed events)
{
  "request": {
    "path": "/v1/messages",
    "body": {
      "model": "claude-opus-5-5",
      "messages": [{ "role": "user", "content": "Summarise this ticket…" }]
    }
  },
  "interactions": [{
    "status": 200,
    "latency_ms": 2412,
    "body": { "content": [{ "type": "text", "text": "The customer wants…" }] },
    "usage": { "input_tokens": 1200, "output_tokens": 300 }
  }]
}

Honest status

Promptape is brand new. Here's what works today and what's next.

v0.1

Available now

OpenAI and Anthropic, streaming, four modes, secret-safe tapes, cost receipts, Docker. Tested with the official Python and TypeScript SDKs.

v0.5

Next

Gemini, pretend outages and rate limits for testing, pytest and Vitest plugins, a GitHub Action.

v1.0

Later

A free local AI model when you have no API budget, alerts when answers drift, a tape browser.

v2.0

Someday

Pretend tools and MCP servers, so whole AI agents can be tested offline.

Good to know: replays test your code, not the AI. To check whether the model itself got better or worse, record fresh answers on purpose with --mode record. Gemini's native API, realtime voice APIs and file uploads aren't fully supported yet.
